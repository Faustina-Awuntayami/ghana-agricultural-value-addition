# GLSS 7 Variable Dictionary

**Project:** Agricultural Value Addition and Commercialization among Ghanaian Farm Households

This document records every GLSS variable used in the analysis, what it measures, and why it is included in the research.

| Variable | Meaning                              | Data Type        | Research Role                       |
| -------- | ------------------------------------ | ---------------- | ----------------------------------- |
| hid      | Household Identifier                 | Character        | Merge key across GLSS datasets.     |
| s8gact   | Processing activity undertaken       | Character        | Type of value-added product.        |
| s8gq1    | Person responsible for processing    | Numeric          | Household labour/gender analysis.   |
| s8gq4    | Number of months processing occurred | Numeric          | Processing intensity.               |
| s8gq6a   | Quantity processed                   | Numeric          | Scale of processing.                |
| s8gq7    | Labour cost of processing            | Numeric          | Processing cost variable.           |
| s8gq9    | Other processing costs               | Numeric          | Total processing cost.              |
| s8gq10   | Whether processed products were sold | Labelled numeric | Commercialization indicator.        |
| s8gq11a  | Quantity sold                        | Numeric          | Market participation.               |
| s8gq12   | Value of processed products sold     | Numeric          | Primary outcome variable.           |
| region   | Administrative region                | Labelled numeric | Geographic control variable.        |
| loc2     | Rural or Urban location              | Labelled numeric | Market access control variable.     |
| WTA_S    | Sampling weight                      | Numeric          | Nationally representative analysis. |
